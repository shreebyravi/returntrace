# ReturnTrace: Look and feel

- **Mood:** a calm, professional B2B tool for careful decisions. Light background, one indigo accent, plenty of white space.
- **Type:** Inter for text, JetBrains Mono for IDs, serials, amounts and timestamps.
- **Action colours:** green = refund review, blue = replacement review, amber = request more evidence, violet = escalate, red = rejection review. Red is used sparingly, because rejection is the rarest and most serious outcome.
- **Screens:** Story, Dashboard, Case queue, Investigation (case, source records, code checks, steps, findings and review), Review and audit, Evaluation.
- **Rules for the page:** facts, contradictions and missing evidence are always shown apart; every finding links to its source; recorded runs are labelled as recorded; the boundary sentence sits under every decision; no emoji icons; neutral wording everywhere.
- **Tokens** are defined once at the top of `index.html` (`:root`).
