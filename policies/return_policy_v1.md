# Dunvale Market: Return Policy, version 1 (fictional)

Policy ID: POL-RET-V1. Cite as "Return v1 2.1".
**Applies to:** orders placed from 1 January 2025 to 30 September 2026.

## 1. Return window

1.1 Customers may return any item within **14 days** of delivery, for any reason.
1.2 Days are counted from the courier's delivery-to-customer event to the return request time.

## 2. Product identity and condition

2.1 The returned item must be the item sold: same SKU and, for serialised items, the same serial number as the dispatch record.
2.2 Items returned for a fault are eligible for a refund or replacement within the window if the fault is confirmed at inspection.
2.3 Missing accessories or packaging may reduce the refund. A specialist decides the amount.

## 3. Disputed returns

3.1 When identity, condition or contents are disputed, the case is investigated before any refund decision.
3.2 The refund amount is the item price paid. Delivery fees are not refunded.
