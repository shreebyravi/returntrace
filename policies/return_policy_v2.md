# Dunvale Market: Return Policy, version 2 (fictional)

Policy ID: POL-RET-V2. Cite as "Return v2 1.2".
**Applies to:** return requests made on or after 1 October 2026.

## 1. Return window

1.1 Home and other non-electronic items: **14 days** from delivery.
1.2 Electronics: **7 days** from delivery.
1.3 Days are counted from the courier's delivery-to-customer event to the return request time.

## 2. Product identity, condition and claims

2.1 The returned item must be the item sold: same SKU and, for serialised items, the same serial number as the dispatch record.
2.2 Items returned for a fault are eligible for a refund or replacement within the window if the fault is confirmed at inspection.
2.3 Claims that an item arrived damaged need a short description of the damage and at least one photo, sent within 48 hours of delivery. Without them, the claim stays open until they are provided.
2.4 Missing accessories or packaging may reduce the refund. A specialist decides the amount.

## 3. Disputed returns

3.1 When identity, condition or contents are disputed, the case is investigated before any refund decision.
3.2 The refund amount is the item price paid. Delivery fees are not refunded.
